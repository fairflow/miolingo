# The acceptance run of the slimmed suite (15 October 2026)

Step 4 of the overseer's agents in locus `docs/neolingo-test-design.md`, section 5 (P4: a suite's power is measured by
putting the old faults back and counting which checks fail). Each historical fault of classes B to E and G (section 2
of the design) that a test can reach was put back. This was never done on `main` or in this folder: the model faults
went into a throwaway locus worktree at `main` d533e3d (its `.lake` cloned with `cp -Rc`), and the host faults into a
throwaway copy of this folder with its own copy of the store. Each copy was removed afterwards. Ids and descriptions
only; no user data.

The checks named below:
- **model guards**: the model's own property `#guard`s in `Miolingo/Neo.lean`, checked by the gate's first step
  (`lake build neolingo`).
- **runs**: `neolingo runs`, each press's test and the 44 assertions of the named runs.
- **regression**: the regression module `NeoRegression` (cases M1 to M16).
- **proofs, witnesses**: `NeoFacts` (a proof file), `NeoVisTest`, `NeoLookTest`, `NeoCells`.
- **walks**: the gate's three short walks.
- **H1**: `tests/check_suite.py`.
- The host's checks are named by file and case.

Every model fault was planted with the model's own guards in force, and planted again with them evaluated but not
enforced (`#guard` read as `#eval`), so that each later check also ran. A check that does not appear in a row passed.
**H1 cannot see a model fault.** The suite it replays is generated by the same model, so H1 checks the host against
the model, not the behaviour (P7). The walks failed on none of the 16 model faults.
