## Part A: Foundational Guide to Brazilian Portuguese Phonetics

### The IPA System: Quick Orientation

If you already understand IPA moderately well, this section provides reference pointers specific to Brazilian Portuguese. The most crucial differences from other languages:

- **Nasal vowels** use the tilde diacritic: \(ɐ̃, ẽ, ĩ, õ, ũ\)
- **Palatalized consonants** appear frequently: \(tʃ, dʒ, ɲ, ʎ\)
- **Two "r" sounds** exist: uvular fricative \(ʁ\) vs. alveolar tap \(ɾ\)
- **Open vs. closed vowels** for mid-vowels: \(ɛ\) vs. \(e\), \(ɔ\) vs. \(o\)

### Brazilian Portuguese Oral Vowels

**Seven vowels in stressed syllables**[160][162][164]:

| Letter | IPA | Description | Context | Example |
|--------|-----|-------------|---------|---------|
| A | /a/ | Open front vowel, unrounded | Stressed: *aqui* \(aˈki\) | *aqui* = \(a.ˈki\) (here) |
| A | /ɐ/ | Central vowel, unrounded | Unstressed: *coisa* \(ˈkojzɐ\) | *coisa* = \(ˈkojzɐ\) (thing) |
| E | /e/ | Close front vowel, unrounded | Stressed closed: *você* \(voˈse\) | *você* = \(voˈse\) (you) |
| E | /ɛ/ | Open front vowel, unrounded | Stressed open: *até* \(aˈtɛ\) | *até* = \(aˈtɛ\) (until) |
| E | /ɪ/ | Near-close front vowel | Monosyllabic words: *que* \(kɪ\) | *que* = \(kɪ\) (that) |
| I | /i/ | Close front vowel, unrounded | Always: *impo**ssível* | *impossível* = \(ĩ.pɔˈsivɛw\) (impossible) |
| O | /o/ | Close back vowel, rounded | Stressed closed: *pouco* \(ˈpowku\) | *pouco* = \(ˈpowku\) (little) |
| O | /ɔ/ | Open back vowel, rounded | Stressed open: *como* \(ˈkɔmu\) | *como* = \(ˈkɔmu\) (how) |
| O | /ʊ/ | Near-close back vowel, rounded | Monosyllabic: *som* = \(sõ\) → emphasized \(sʊ\) | Related to unstressed |
| U | /u/ | Close back vowel, rounded | Always: *tudo* \(ˈtudu\) | *tudo* = \(ˈtudu\) (everything) |

**Stress rule for vowel quality**: Only vowels in **stressed syllables** can be pronounced as open vowels \(/ɛ, ɔ/\). Unstressed mid-vowels reduce to close variants \(/e, o/\) or further reduce to \(/ɪ, ʊ/\) in word-final position[160][162].

### Brazilian Portuguese Nasal Vowels

**Five nasal vowels** (no open nasal vowels exist)[122][160][163]:

| Letter(s) | IPA | Description | Example |
|-----------|-----|-------------|---------|
| Ã, AM, AN | /ɐ̃/ | Nasalized central vowel | *criança* = \(kɾiˈɐ̃sɐ\) (child) |
| EM, EN | /ẽ/ | Nasalized close-mid front vowel | *tempo* = \(ˈtẽpu\) (time) |
| IM, IN | /ĩ/ | Nasalized close front vowel | *sim* = \(sĩ\) (yes) |
| OM, ON, Õ | /õ/ | Nasalized close-mid back vowel | *onde* = \(ˈõdʒi\) (where) |
| UM, UN | /ũ/ | Nasalized close back vowel | *mundo* = \(ˈmũdu\) (world) |

**Formation rule**: Vowels become nasalized when:
1. Written with tilde (~): *pão* \(ˈpɐ̃w̃\), *não* \(ˈnɐ̃w̃\)
2. Followed by **m** or **n** in the same syllable: *cama* \(ˈkɐ̃mɐ\) (bed), *lindo* \(ˈlĩdu\) (beautiful)

**Special nasal diphthongs**[41][122]:

- **-ÃO ending**: Creates diphthong \(ɐ̃w̃\)
  - *pão* = \(ˈpɐ̃w̃\) (bread)
  - *mão* = \(ˈmɐ̃w̃\) (hand)
  - *falaram* = \(faˈlaɾɐ̃w̃\) (they spoke) — the final *-am* → \(ɐ̃w̃\)

- **-ÃE ending**: Creates diphthong \(ɐ̃j̃\)
  - *limões* = \(liˈmõjs̃\) (lemons)
  - *falarem* = \(faˈlaɾɐ̃j̃\) (they speak - future subjunctive)

### Brazilian Portuguese Consonants

**Key consonants with IPA symbols**[117][118][161]:

| Consonant | IPA | Context | Example |
|-----------|-----|---------|---------|
| B | /b/ | All positions | *bebê* = \(beˈbe\) (baby) |
| C before A, O, U | /k/ | → hard sound | *carro* = \(ˈkaʁu\) (car) |
| C before E, I | /s/ | → soft sound | *cena* = \(ˈsenɐ\) (scene) |
| Ç | /s/ | Before A, O, U | *cabeça* = \(kabeˈsɐ\) (head) |
| CH | /ʃ/ | Always | *chave* = \(ˈʃavɪ\) (key) |
| D | /d/ or /dʒ/ | Before /i/: becomes \(/dʒ/\) | *de* = \(dʒɪ\) (of) |
| F | /f/ | All positions | *fado* = \(ˈfadu\) (fate) |
| G before A, O, U | /ɡ/ | → hard sound | *gato* = \(ˈɡatu\) (cat) |
| G before E, I | /ʒ/ | → soft sound | *gelo* = \(ˈʒɛlu\) (ice) |
| GU before E, I | /ɡ/ | Maintains hard sound | *guerra* = \(ˈɡɛʁɐ\) (war) |
| J | /ʒ/ | All positions | *jogo* = \(ˈʒɔɡu\) (game) |
| L | /l/ or /w/ | Syllable-final: vocalized to \(/w/\) | *mal* = \(ˈmaʊ\) (bad) |
| LH | /ʎ/ | Always | *filho* = \(ˈfiʎu\) (son) |
| M | /m/ | Before consonants & word-final | *mãe* = \(ˈmɐ̃j\) (mother) |
| N | /n/ | Before consonants & word-final | *nós* = \(ˈnɔjs̃\) (we) |
| NH | /ɲ/ | Always | *tenho* = \(ˈtɛɲu\) (I have) |
| P | /p/ | All positions | *pão* = \(ˈpɐ̃w̃\) (bread) |
| Q (always + U) | /k/ | Before A, E, O | *quase* = \(ˈkwazɪ\) (almost) |
| R word-initial or after consonant | /ʁ/ | Uvular fricative | *rato* = \(ˈʁatu\) (rat) |
| R intervocalic | /ɾ/ | Alveolar tap | *caro* = \(ˈkaɾu\) (expensive) |
| RR | /ʁ/ | Between vowels → hard sound | *carro* = \(ˈkaʁu\) (car) |
| S word-initial or before voiceless C | /s/ | → alveolar fricative | *sal* = \(ˈsaʊ\) (salt) |
| S between vowels or before voiced C | /z/ | → voiced fricative | *rosa* = \(ˈʁɔza\) (rose) |
| SS | /s/ | Between vowels → always voiceless | *massa* = \(ˈmasɐ\) (dough) |
| T | /t/ or /tʃ/ | Before /i/: becomes \(/tʃ/\) | *tio* = \(ˈtʃiu\) (uncle) |
| V | /v/ | All positions | *veia* = \(ˈvejɐ\) (vein) |
| X | /ʃ/ | Typically | *xá* = \(ʃɑ̃\) (chess piece) |
| Z | /z/ | Typically | *zona* = \(ˈzɔnɐ\) (zone) |

**Palatalization pattern**: Before the vowel /i/, both /d/ and /t/ become affricates[161]:
- *tio* (uncle) = \(ˈtʃiu\) not \(ˈtiu\)
- *de* (of) = \(dʒi\) not \(di\)

### Stress and Rhythm

Brazilian Portuguese typically stresses the **penultimate (second-to-last) syllable** if it contains a full vowel[144]:
- *CASa* = \(ˈkazɐ\) (house)
- *TAMANho* = \(taˈmɐɲu\) (size)
- *COMdo* = \(ˈkõdu\) (when)

## 1. Pronunciation: The Critical Difference

### Vowel Systems

**Spanish** has 5 vowel sounds; **Portuguese has 14 (9 oral + 5 nasal)**[15]. This is the single biggest pronunciation challenge.

### Nasal Vowels (Unique Feature)

Portuguese vowels become nasal when:
- Written with tilde (~): **ã**, **õ**
- Followed by **m** or **n** at end of syllable: *campo* = \(ˈkɐ̃pu\), *quando* = \(ˈkwɐ̃du\)

The five nasal vowels:
- **ã/am/an**: *maçã* = \(maˈsɐ̃\) (apple), *cama* = \(ˈkɐ̃mɐ\) (bed)
- **em/en**: *tempo* = \(ˈtẽpu\) (time), *centro* = \(ˈsẽtɾu\) (center)
- **im/in**: *fim* = \(ˈfĩ\) (end), *lindo* = \(ˈlĩdu\) (beautiful)
- **õ/om/on**: *põe* = \(ˈpõj\) (puts), *bom* = \(ˈbõ\) (good)
- **um/un**: *algum* = \(aʊˈɡũ\) (some), *mundo* = \(ˈmũdu\) (world)

**Key nasal diphthongs**[41]:
- **-ão** = /ɐ̃w̃/: *mão* = \(ˈmɐ̃w̃\) (hand), *pão* = \(ˈpɐ̃w̃\) (bread)
- **-õe** = /õj̃/: *limões* = \(liˈmõjs̃\) (lemons)
- Words ending in **-am** = /ɐ̃w̃/: *falam* = \(ˈfaɾɐ̃w̃\) (they speak)
- Words ending in **-em** = /ɐ̃j̃/: *veem* = \(ˈvɛ̃j̃\) (they see)

### Vowel Reduction (European Portuguese vs. Brazilian Portuguese)

**European Portuguese**: Reduces unstressed vowels dramatically[98]:
- Unstressed **o** → /u/: *porto* sounds like "portu" = \(ˈpɔɾtu\)
- Unstressed **e** often becomes schwa or disappears[35]

**Brazilian Portuguese**: Maintains more open, clear vowels across syllables[95]:
- *excelente* = \(eseˈlẽtʃi\) — every vowel pronounced clearly
- This makes BP more accessible for learners

## 2. Articles and Gender

### Definite and Indefinite Articles

Like Spanish, Portuguese has gendered articles[33][39]:

| | **Masculine** | **Feminine** |
|---------|-----------|----------|
| **Definite (the)** | o \(u\) / os \(uʃ\) | a \(a\) / as \(aʃ\) |
| **Indefinite (a/an, some)** | um \(ũ\) / uns \(ũs̃\) | uma \(ˈũmɐ\) / umas \(ˈũmɐs̃\) |

**Key difference from Spanish**: Portuguese uses definite articles more extensively[36]:
- With possessives: *a minha casa* = \(a ˈmĩɲɐ ˈkazɐ\) (my house) vs. Spanish *mi casa*
- With proper names (colloquial): *o João* = \(u ʒuˈɐ̃w̃\) (João)
- With country names: *o Brasil* = \(u bɾaˈziʊ\), *a França* = \(a ˈfɾɐ̃sɐ\)

### Gender False Friends

Many words have opposite genders[15]:
- *orden* (order): masculine in Spanish, feminine in Portuguese (*ordem* \(ˈɔɾdɛ̃j\))
- *leche/leite* (milk): feminine in Spanish, masculine in Portuguese (*leite* = \(ˈlɛjtʃi\))
- *sal* (salt): feminine in Spanish, masculine in Portuguese (*sal* = \(ˈsaʊ\))

## 3. Contractions: Mandatory in Portuguese

**Portuguese has extensive mandatory contractions**[34][37][40], much more than Spanish:

### With **de** (of, from):
- de + o = **do** \(du\) | de + a = **da** \(da\)
- de + os = **dos** \(duʃ\) | de + as = **das** \(daʃ\)
- de + ele = **dele** \(dɛˈlɪ\) | de + este = **deste** \(ˈdɛʃtʃi\)

### With **em** (in, on, at):
- em + o = **no** \(nu\) | em + a = **na** \(na\)
- em + os = **nos** \(nuʃ\) | em + as = **nas** \(naʃ\)
- em + um = **num** \(nũ\) | em + uma = **numa** \(ˈnũmɐ\)

### With **por** (by, through, for):
- por + o = **pelo** \(ˈpɛlu\) | por + a = **pela** \(ˈpɛlɐ\)
- por + os = **pelos** \(ˈpɛluʃ\) | por + as = **pelas** \(ˈpɛlɐs̃\)

### With **para** (to, for) - informal/colloquial:
- para + o = **pro** \(pru\) | para + a = **pra** \(pɾa\)

### With **a** (to, at):
- a + o = **ao** \(ˈaw̃\) | a + a = **à** \(a\) (with grave accent)
- a + os = **aos** \(ˈaws̃\) | a + as = **às** \(aʃ\)

## 4. Nouns, Adjectives, and Agreement

### Adjective Agreement

Like Spanish and French, **adjectives must agree in gender and number** with nouns[47][50]:

- *o gato preto* = \(u ˈɡatu ˈpretu\) (the black cat - masc. sing.)
- *a gata preta* = \(a ˈɡatɐ ˈprɛtɐ\) (the black cat - fem. sing.)
- *os gatos pretos* = \(uʃ ˈɡatuʃ ˈpretʃuʃ\) (the black cats - masc. pl.)
- *as gatas pretas* = \(aʃ ˈɡatɐʃ ˈprɛtɐʃ\) (the black cats - fem. pl.)

**Mixed gender**: If nouns are different genders, adjective becomes masculine plural[50]:
- *O cão e a gata são barulhentos* = \(u ˈkɐ̃w̃ i ɐ ˈɡatɐ ˈsɐ̃w̃ baɾuˈʎɛ̃tuʃ\) (The dog and the cat are noisy)

### Adjective Position

**Default**: adjectives follow nouns (like Spanish):
- *um carro vermelho* = \(ũ ˈkaʁu vɛɾˈmɛʎu\) (a red car)

**Emphasis**: placing adjective before noun adds emphasis or changes meaning[79]:
- *um grande homem* = \(ũ ˈɡɾɐ̃dʒi ˈɔmẽ\) (a great man - important)
- *um homem grande* = \(ũ ˈɔmẽ ˈɡɾɐ̃dʒi\) (a big/tall man - physical size)

### Pluralization

Basic rule: add **-s** to words ending in vowels[2]:
- *casa* = \(ˈkazɐ\) → *casas* = \(ˈkazɐs̃\) (house/houses)
- *gato* = \(ˈɡatu\) → *gatos* = \(ˈɡatuʃ\) (cat/cats)

**Complex rules** for other endings[5]:
- Words ending in **-ão** → **-ões**, **-ães**, or **-ãos** (no consistent rule!)
  - *lição* = \(liˈsɐ̃w̃\) → *lições* = \(liˈsõjs̃\) (lesson/lessons)
  - *cão* = \(ˈkɐ̃w̃\) → *cães* = \(ˈkɐ̃j̃s̃\) (dog/dogs)
  - *irmão* = \(iɾˈmɐ̃w̃\) → *irmãos* = \(iɾˈmɐ̃w̃ʃ\) (brother/brothers)

## 5. Pronouns: Subject and Object

### Subject Pronouns

| | **Portuguese** | **IPA** | **Spanish** |
|-----|------------|---------|---------|
| I | eu | /ˈew/ | yo |
| You (informal) | tu | /tu/ | tú |
| You (formal) | você | /voˈse/ | usted |
| He/She | ele/ela | /ˈɛlɪ/ / /ˈɛlɐ/ | él/ella |
| We | nós | /ˈnɔs̃/ | nosotros/as |
| You (pl. informal) | vós* | /ˈvɔs̃/ | vosotros/as |
| You (pl. formal) | vocês | /vuˈseʃ/ | ustedes |
| They | eles/elas | /ˈɛliʃ/ / /ˈɛlɐʃ/ | ellos/ellas |

*\*vós* is archaic in modern Portuguese; **vocês** is used for both informal and formal plural[5]

**Similarity to Spanish**: Portuguese often drops subject pronouns when context is clear[4].

### Object Pronoun Placement: Major Difference!

**Spanish**: Reflexive and object pronouns placed before conjugated verbs or after infinitives/gerunds[13].

**Portuguese** (European) has three positions[48][51]:

**1. Enclisis** (after verb with hyphen) - **default in EP**:
- *Vejo-te* = \(vɛˈʒu tɪ\) (I see you)
- *Ele comprou-o* = \(ˈɛlɪ kõˈpɾow u\) (He bought it)

**2. Proclisis** (before verb) - required with "magnetic" words[48]:
- Negatives: *Não te vejo* = \(ˈnɐ̃w̃ tɪ vɛˈʒu\) (I don't see you)
- Question words: *Quando te vejo?* = \(ˈkwɐ̃du tɪ vɛˈʒu\) (When do I see you?)
- Subordinating conjunctions: *porque te amo* = \(puɾˈkɪ tɪ ˈɐmu\) (because I love you)
- *já, sempre, ainda, nunca, nada, ninguém*

**3. Mesoclisis** (inside verb) - future and conditional only[48]:
- *Ver-te-ei* = \(vɛɾ tɪ ɛj\) (I will see you)
- *Comprá-lo-ia* = \(kõˈpɾa lu i.ɐ\) (I would buy it)

**Brazilian Portuguese** generally uses proclisis more frequently, similar to Spanish placement[95].

### Direct vs. Indirect Object Pronouns

| | **Direct** | **IPA** | **Indirect** | **IPA** |
|----|--------|---------|----------|---------|
| me | me | /mi/ | me | /mi/ (to me) |
| you (inf.) | te | /tɪ/ | te | /tɪ/ (to you) |
| him/her/you | o/a | /u/ / /ɐ/ | lhe | /ʎɪ/ (to him/her/you) |
| us | nos | /nuʃ/ | nos | /nuʃ/ (to us) |
| them/you (pl.) | os/as | /uʃ/ / /aʃ/ | lhes | /ʎis̃/ (to them/you) |

**Inflected forms** after nasal sounds[51]:
- After **-m, -ão, -õe**: o/a → **no/na**
  - *Puseram* + *o* = *Puseram-no* = \(puˈseɾɐ̃w̃ nu\) (They put it)
- After **-r, -s, -z**: o/a → **lo/la**
  - *Vê-lo* = \(vɛ lu\) (to see it - infinitive *ver* + *o*)

## 6. Reflexive Verbs

### Formation and Usage

Portuguese reflexive verbs work similarly to Spanish but with different pronoun placement (see above).

**Common reflexive verbs**[52]:
- *chamar-se* = \(tʃaˈmaɾ sɪ\) (to be called/named)
- *levantar-se* = \(levɐ̃ˈtaɾ sɪ\) (to get up)
- *sentar-se* = \(sẽˈtaɾ sɪ\) (to sit down)
- *vestir-se* = \(veʃˈtʃiɾ sɪ\) (to get dressed)
- *lembrar-se* = \(lẽˈbɾaɾ sɪ\) (to remember)
- *esquecer-se* = \(eskeˈseɾ sɪ\) (to forget)
- *divertir-se* = \(diveɾˈtʃiɾ sɪ\) (to have fun)
- *sentir-se* = \(sẽˈtʃiɾ sɪ\) (to feel)
- *preocupar-se* = \(pɾiɔkuˈpaɾ sɪ\) (to worry)
- *zangar-se* = \(zɐ̃ˈɡaɾ sɪ\) (to get angry)
- *apaixonar-se* = \(apajʃɔˈnaɾ sɪ\) (to fall in love)

**Examples with proclisis** (before verb) - Brazilian style[49]:
- *Eu **me** chamo João* = \(ˈew mi ˈʃamu ʒuˈɐ̃w̃\) (I am called João)
- *Quando **te** levantas?* = \(ˈkwɐ̃du tɪ levɐ̃ˈtaʃ\) (When do you get up?)

**Examples with enclisis** (after verb) - European style[49]:
- *Chamo-**me** João* = \(ˈʃamu mi ʒuˈɐ̃w̃\) (I am called João)
- *Levantei-**me** cedo* = \(levɐ̃ˈtej mi ˈsedu\) (I got up early)

## 7. Verb Conjugation: Overview

### Three Conjugation Groups

Like Spanish, Portuguese verbs end in **-ar**, **-er**, **-ir**:
- *amar* = \(aˈmaɾ\) (to love)
- *correr* = \(kuˈʁɛɾ\) (to run)
- *partir* = \(paɾˈtʃiɾ\) (to leave)

### Present Tense - Regular Verbs

**-AR verbs**: *falar* = \(faˈlaɾ\) (to speak)

| | **Ending** | **Example** | **IPA** |
|-----|-------|---------|---------|
| eu | -o | fal**o** | \(ˈfalu\) |
| tu | -as | fal**as** | \(ˈfalaʃ\) |
| ele/você | -a | fal**a** | \(ˈfala\) |
| nós | -amos | fal**amos** | \(faˈlamuʃ\) |
| vós | -ais | fal**ais** | \(faˈlajs̃\) |
| eles/vocês | -am | fal**am** | \(ˈfaɾɐ̃w̃\) |

**-ER verbs**: *comer* = \(kuˈmeɾ\) (to eat)

| | **Ending** | **Example** | **IPA** |
|-----|-------|---------|---------|
| eu | -o | com**o** | \(ˈkɔmu\) |
| tu | -es | com**es** | \(ˈkɔmɪʃ\) |
| ele/você | -e | com**e** | \(ˈkɔmɪ\) |
| nós | -emos | com**emos** | \(kuˈmemuʃ\) |
| vós | -eis | com**eis** | \(kuˈmejs̃\) |
| eles/vocês | -em | com**em** | \(ˈkɔmɛ̃j̃\) |

**-IR verbs**: *partir* = \(paɾˈtʃiɾ\) (to leave)

| | **Ending** | **Example** | **IPA** |
|-----|-------|---------|---------|
| eu | -o | part**o** | \(ˈpaɾtu\) |
| tu | -es | part**es** | \(ˈpaɾtʃis̃\) |
| ele/você | -e | part**e** | \(ˈpaɾtʃi\) |
| nós | -imos | part**imos** | \(paɾˈtʃimuʃ\) |
| vós | -is | part**is** | \(paɾˈtʃis̃\) |
| eles/vocês | -em | part**em** | \(ˈpaɾtʃẽj̃\) |

**Similarity to Spanish**: Patterns are nearly identical, but pronunciation differs significantly (especially nasal *-am* and *-em* endings).

## 8. Key Irregular Verbs

### Ser (to be - permanent) vs. Estar (to be - temporary)

**Ser** = \(sɛɾ\) - permanent characteristics, identity, time, origin[93]:

| | **Ser** | **IPA** | **Estar** | **IPA** |
|----|-----|-------|-------|---------|
| eu | sou | \(ˈsow\) | estou | \(eʃˈtow\) |
| tu | és | \(ˈɛʃ\) | estás | \(eʃˈtaʃ\) |
| ele/você | é | \(ˈɛ\) | está | \(eʃˈta\) |
| nós | somos | \(ˈsomuʃ\) | estamos | \(eʃtaˈmuʃ\) |
| vós | sois | \(ˈsɔjs̃\) | estais | \(eʃtaˈjs̃\) |
| eles/vocês | são | \(ˈsɐ̃w̃\) | estão | \(eʃtɐ̃w̃\) |

**Uses of Ser**[93]:
- Identity: *Eu sou professor* = \(ˈew ˈsow pɾufeˈsoɾ\) (I am a teacher)
- Nationality: *Ela é brasileira* = \(ˈɛlɐ ˈɛ bɾaziˈlejɾɐ\) (She is Brazilian)
- Characteristics: *O livro é interessante* = \(u ˈlivɾu ˈɛ ĩtɛɾeˈsɐ̃tʃi\) (The book is interesting)
- Time: *São três horas* = \(ˈsɐ̃w̃ ˈtɾɛʃ ˈɔɾɐʃ\) (It's three o'clock)
- Possession: *Este livro é meu* = \(ˈɛʃtɪ ˈlivɾu ˈɛ ˈmew\) (This book is mine)
- Origin: *Somos de Lisboa* = \(ˈsomuʃ dʒi liʒˈbɔa\) (We are from Lisbon)

**Uses of Estar** = \(eʃˈtaɾ\)[93]:
- Location (temporary): *Estou em casa* = \(eʃˈtow ẽ ˈkazɐ\) (I am at home)
- Temporary states: *Estou cansado* = \(eʃˈtow kɐ̃ˈsadu\) (I am tired)
- Emotions: *Ela está feliz* = \(ˈɛlɐ eʃˈta feˈliʃ\) (She is happy)
- Progressive tenses: *Estou a estudar* = \(eʃˈtow a eʃtuˈdaɾ\) / *Estou estudando* = \(eʃˈtow eʃtuˈdɐ̃du\) (I am studying)

**Note**: Like Spanish *ser* and *ir*, Portuguese forms are identical in preterite[93].

## 9. Past Tenses: Preterite vs. Imperfect

### Pretérito Perfeito (Preterite) - Completed Actions

Used for **specific, completed actions** with defined beginning/end[63][66][69].

**Regular conjugations**[63]:

**-AR**: *falar* = \(faˈlaɾ\)
- *falei* = \(faˈlej\), *falaste* = \(faˈlaʃtɪ\), *falou* = \(faˈlow\), *falámos* = \(faˈlamuʃ\), *falastes* = \(faˈlaʃtɪʃ\), *falaram* = \(faˈlaɾɐ̃w̃\)

**-ER**: *comer* = \(kuˈmeɾ\)
- *comi* = \(kuˈmi\), *comeste* = \(kuˈmeʃtɪ\), *comeu* = \(kuˈmew\), *comemos* = \(kuˈmemuʃ\), *comestes* = \(kuˈmeʃtɪʃ\), *comeram* = \(kuˈmeɾɐ̃w̃\)

**-IR**: *partir* = \(paɾˈtʃiɾ\)
- *parti* = \(paɾˈtʃi\), *partiste* = \(paɾˈtʃiʃtɪ\), *partiu* = \(paɾˈtʃiu\), *partimos* = \(paɾˈtʃimuʃ\), *partistes* = \(paɾˈtʃiʃtɪʃ\), *partiram* = \(paɾˈtʃiɾɐ̃w̃\)

**Time expressions** that signal preterite[63]:
- *ontem* = \(õˈtẽ\) (yesterday)
- *na semana passada* = \(nɐ sɪˈmanɐ paˈsadɐ\) (last week)
- *em 2020* = \(ẽ dõj miʃ ɪ ˈvĩtɪ\) (in 2020)
- *às três horas* = \(aʃ ˈtɾɛʃ ˈɔɾɐʃ\) (at three o'clock)

**Examples**[66]:
- *Ontem, fiz exercício físico* = \(õˈtẽ fiʃ eʃɛɾˈsisju ˈfiziku\) (Yesterday, I exercised)
- *A reunião começou às nove* = \(a ʁiuˈniɐ̃w̃ kumeˈsow aʃ ˈnɔvi\) (The meeting started at nine)

### Pretérito Imperfeito (Imperfect) - Ongoing/Habitual Actions

Used for **habitual actions, descriptions, ongoing situations** in past[63][66][69].

**Regular conjugations**[63]:

**-AR**: *falar* = \(faˈlaɾ\)
- *falava* = \(faˈlavɐ\), *falavas* = \(faˈlavɐʃ\), *falava* = \(faˈlavɐ\), *falávamos* = \(faˈlavɐmuʃ\), *faláveis* = \(faˈlaveis̃\), *falavam* = \(faˈlavɐ̃w̃\)

**-ER/-IR**: *comer* = \(kuˈmeɾ\) / *partir* = \(paɾˈtʃiɾ\)
- *comia* = \(kuˈmiɐ\), *comias* = \(kuˈmiɐʃ\), *comia* = \(kuˈmiɐ\), *comíamos* = \(kuˈmiɐmuʃ\), *comíeis* = \(kuˈmiejs̃\), *comiam* = \(kuˈmiɐ̃w̃\)
- *partia* = \(paɾˈtʃiɐ\), *partias* = \(paɾˈtʃiɐʃ\), *partia* = \(paɾˈtʃiɐ\), *partíamos* = \(paɾˈtʃiɐmuʃ\), *partíeis* = \(paɾˈtʃiejs̃\), *partiam* = \(paɾˈtʃiɐ̃w̃\)

**Only 4 irregular verbs**[63]:
- **ser** = \(sɛɾ\): *era* = \(ˈɛɾɐ\), *eras* = \(ˈɛɾɐʃ\), *era* = \(ˈɛɾɐ\), *éramos* = \(ˈɛɾɐmuʃ\), *éreis* = \(ˈɛɾejs̃\), *eram* = \(ˈɛɾɐ̃w̃\)
- **ter** = \(tɛɾ\): *tinha* = \(ˈtĩɲɐ\), *tinhas* = \(ˈtĩɲɐʃ\), *tinha* = \(ˈtĩɲɐ\), *tínhamos* = \(ˈtĩɲɐmuʃ\), *tínheis* = \(ˈtĩɲejs̃\), *tinham* = \(ˈtĩɲɐ̃w̃\)
- **vir** = \(viɾ\): *vinha* = \(ˈvĩɲɐ\), *vinhas* = \(ˈvĩɲɐʃ\), *vinha* = \(ˈvĩɲɐ\), *vínhamos* = \(ˈvĩɲɐmuʃ\), *vínheis* = \(ˈvĩɲejs̃\), *vinham* = \(ˈvĩɲɐ̃w̃\)
- **pôr** = \(pɔɾ\): *punha* = \(ˈpũɲɐ\), *punhas* = \(ˈpũɲɐʃ\), *punha* = \(ˈpũɲɐ\), *púnhamos* = \(ˈpũɲɐmuʃ\), *púnheis* = \(ˈpũɲejs̃\), *punham* = \(ˈpũɲɐ̃w̃\)

**Time expressions** that signal imperfect[66]:
- *sempre* = \(ˈsẽpɾi\) (always)
- *todos os dias* = \(ˈtɔduʃ uʃ ˈdiɐʃ\) (every day)
- *normalmente* = \(nɔɾmaʊˈmẽtʃi\) (normally)
- *antigamente* = \(ɐ̃tiɡɐˈmẽtʃi\) (in the past, formerly)
- *enquanto* = \(ẽˈkwɐ̃tu\) (while)

**Examples**[66]:
- *Fazia exercício todos os dias quando era mais jovem* = \(faˈziɐ eʃɛɾˈsisju ˈtɔduʃ uʃ ˈdiɐʃ ˈkwɐ̃du ˈɛɾɐ ˈmajs̃ ʒuˈvẽ\) (I exercised every day when I was younger)
- *O tempo estava ótimo e o céu era azul* = \(u ˈtẽpu eʃtaˈva ˈɔtimu i u ˈsɛw ˈɛɾɐ aˈzuʊ\) (The weather was great and the sky was blue)
- *Enquanto eu estudava, o meu irmão jogava* = \(ẽˈkwɐ̃tu ˈew eʃtuˈdavɐ u ˈmew iɾˈmɐ̃w̃ ʒuˈɡavɐ\) (While I was studying, my brother was playing)

**Key distinction**[69]:
- **Preterite** = one-time, completed: *Ontem, fui ao mercado* = \(õˈtẽ ˈfuj aw̃ meɾˈkadu\) (Yesterday I went to the market)
- **Imperfect** = habitual, repeated: *Todos os domingos, ia ao mercado* = \(ˈtɔduʃ uʃ duˈmĩɡuʃ ˈiɐ aw̃ meɾˈkadu\) (Every Sunday I used to go to the market)

### Combined Usage

Often both tenses appear together[66]:
- *Enquanto lia um livro, ouvi um barulho* = \(ẽˈkwɐ̃tu liˈa ũ ˈlivɾu ˈowvi ũ baˈɾuʎu\) (While I was reading - imperfect, I heard a noise - preterite)

## 11. The Portuguese Subjunctive: Three Forms!

**Major difference from Spanish**: Portuguese has **three subjunctive tenses**[7][18][21][84], not just two.

### 1. Present Subjunctive - Uncertainty, Desire

Used after expressions of doubt, desire, emotion[84]:
- *Espero que fales* = \(eʃˈpeɾu kɪ ˈfalis̃\) (I hope you speak)
- *Duvido que venha* = \(ˈduvidu kɪ ˈvẽɲɐ\) (I doubt he'll come)
- *É importante que estudem* = \(ɛ ĩpoɾˈtɐ̃tʃi kɪ eʃtuˈdẽj̃\) (It's important that they study)

### 2. Imperfect Subjunctive - Hypothetical Past

Similar to Spanish; used with *se* clauses, contrary-to-fact[84]:
- *Se eu fosse rico...* = \(sɪ ˈew ˈfɔsɪ ˈʁiku\) (If I were rich...)
- *Como se fosse fácil* = \(ˈkomu sɪ ˈfɔsɪ ˈfasiʊ\) (As if it were easy)

### 3. **Future Subjunctive - UNIQUE TO PORTUGUESE!**

**This is the most distinctive feature of Portuguese grammar**. Spanish once had it but it's now archaic.

**Formation**: Take 3rd person plural preterite, remove *-am*, add endings[24]:
- *falar* = \(faˈlaɾ\) → *falaram* = \(faˈlaɾɐ̃w̃\) → *falar-*
- Endings: —, *-es*, —, *-mos*, *-des*, *-em*
- Result: *falar* = \(faˈlaɾ\), *falares* = \(faˈlaɾis̃\), *falar* = \(faˈlaɾ\), *falarmos* = \(falaɾˈmuʃ\), *falardes* = \(falaɾˈdɪʃ\), *falarem* = \(faˈlaɾẽj̃\)

**Usage**: With future conditions that are **likely to happen**[18][27]:

**Triggered by**:
- **quando** = \(ˈkwɐ̃du\) (when): *Quando chegares, liga-me* = \(ˈkwɐ̃du ʃeɡaˈɾis̃ ˈliɡa mi\) (When you arrive, call me)
- **se** = \(sɪ\) (if): *Se tiveres tempo, vem* = \(sɪ tiˈveɾis̃ ˈtẽpu ˈvẽ\) (If you have time, come)
- **assim que** = \(aˈsĩ kɪ\) (as soon as): *Assim que terminar, saio* = \(aˈsĩ kɪ tɛɾmiˈnaɾ ˈsaju\) (As soon as I finish, I'll leave)
- **enquanto** = \(ẽˈkwɐ̃tu\) (while): *Enquanto estiver aqui, ajudo* = \(ẽˈkwɐ̃tu eʃtiˈveɾ aˈki aˈʒudu\) (While I'm here, I'll help)
- **depois de** = \(deˈpɔjʃ dʒi\) (after): *Depois de falares, saio* = \(deˈpɔjʃ dʒi faˈlaɾis̃ ˈsaju\) (After you speak, I'll leave)

**Key difference from Spanish**[21][27]:
- English: "When you go home" (present tense)
- Spanish: *Cuando vayas a casa* (present subjunctive)
- **Portuguese**: *Quando fores a casa* = \(ˈkwɐ̃du ˈfoɾis̃ a ˈkazɐ\) (**future subjunctive**)

### Summary: Which Subjunctive?

- **Present**: Current doubts/desires → *Espero que venhas* = \(eʃˈpeɾu kɪ ˈvẽɲɐʃ\)
- **Imperfect**: Contrary to fact, hypothetical → *Se eu fosse...* = \(sɪ ˈew ˈfɔsɪ\)
- **Future**: Likely future conditions → *Quando chegar...* = \(ˈkwɐ̃du ʃeɡaˈɾ\)

## 12. The Personal Infinitive: Another Portuguese Exclusive!

**The personal infinitive is conjugated for person/number**[19][22][25] - a feature nearly unique to Portuguese among Romance languages.

### Formation

Take regular infinitive, add endings:
- Base: *falar* = \(faˈlaɾ\), *comer* = \(kuˈmeɾ\), *partir* = \(paɾˈtʃiɾ\)
- Endings: —, **-es**, —, **-mos**, **-des**, **-em**

| | **falar** | **IPA** | **comer** | **IPA** | **partir** | **IPA** |
|-----|------|---------|------|---------|------|---------|
| eu | falar | \(faˈlaɾ\) | comer | \(kuˈmeɾ\) | partir | \(paɾˈtʃiɾ\) |
| tu | falares | \(faˈlaɾis̃\) | comeres | \(kuˈmeɾis̃\) | partires | \(paɾˈtʃiɾis̃\) |
| ele | falar | \(faˈlaɾ\) | comer | \(kuˈmeɾ\) | partir | \(paɾˈtʃiɾ\) |
| nós | falarmos | \(falaɾˈmuʃ\) | comermos | \(komeɾˈmuʃ\) | partirmos | \(paɾtʃiɾˈmuʃ\) |
| vós | falardes | \(falaɾˈdɪʃ\) | comerdes | \(komeɾˈdɪʃ\) | partirdes | \(paɾtʃiɾˈdɪʃ\) |
| eles | falarem | \(faˈlaɾẽj̃\) | comerem | \(kuˈmeɾẽj̃\) | partirem | \(paɾˈtʃiɾẽj̃\) |

**Note**: For regular verbs, personal infinitive forms = future subjunctive forms[19]!

### When to Use

**1. After impersonal expressions** (*é + adjective*):
- *É importante ficares em casa* = \(ɛ ĩpoɾˈtɐ̃tʃi fiˈkaɾis̃ ẽ ˈkazɐ\) (It's important for you to stay home)
- *É bom dançarem* = \(ɛ ˈbõ dɐ̃ˈsaɾẽj̃\) (It's good for them to dance)

**2. After prepositions** when subject changes:
- *Antes de saíres, apaga a luz* = \(ˈɐ̃tɪʃ dʒi saˈiɾis̃ aˈpaɡa a ˈluʃ\) (Before you leave, turn off the light)
- *Depois de falarem, saímos* = \(deˈpɔjʃ dʒi faˈlaɾẽj̃ saˈimuʃ\) (After they speak, we'll leave)
- *Para eles entenderem* = \(ˈpaɾa ˈɛliʃ ẽtẽdeˈɾẽj̃\) (For them to understand)
- *Apesar de sermos amigos* = \(aˈpɛzaɾ dʒi ˈsɛɾmuʃ aˈmiɡuʃ\) (Although we are friends)
- *Sem termos dinheiro* = \(ˈsẽ ˈtɛɾmuʃ diˈɲejɾu\) (Without us having money)

**3. With certain expressions**[28]:
- *no caso de* = \(nu ˈkazu dʒi\) (in case of)
- *até* = \(aˈtɛ\) (until)
- *ao* = \(aw̃\) (upon)

**4. When subjects differ in same sentence** (mandatory)[19][31]:
- *Vou ficar até eles chegarem* = \(ˈvow fiˈkaɾ aˈtɛ ˈɛliʃ ʃeɡaˈɾẽj̃\) (I'll stay until they arrive)
- *É difícil para nós entendermos* = \(ɛ diˈfisiʊ ˈpaɾa ˈnɔs̃ ẽtẽdeɾˈmuʃ\) (It's difficult for us to understand)

**Spanish comparison**: Spanish uses only impersonal infinitive; Portuguese conjugates it to clarify subjects[3][22].

## 13. Prepositions: Por vs. Para

Both can mean "for" but have **different functions**[64][67][70]:

### Para - Purpose, Destination, Future

**"Forward-looking"** - indicates goal/purpose[67][70]:

**Uses**:
- **Purpose/goal**: *Estudo para aprender* = \(eʃˈtudu ˈpaɾa apɾẽˈdeɾ\) (I study in order to learn)
- **Destination**: *Vou para Lisboa* = \(ˈvow ˈpaɾa liʒˈbɔa\) (I'm going to Lisbon)
- **Recipient**: *Um presente para ti* = \(ũ pɾiˈzẽtʃi ˈpaɾa ˈtʃi\) (A gift for you)
- **Deadline**: *Para amanhã* = \(ˈpaɾa amaˈɲɐ̃\) (For/by tomorrow)
- **Future time**: *Para mais tarde* = \(ˈpaɾa majs̃ ˈtaɾdʒi\) (For later)

### Por - Reason, Duration, Means

**"Backward-looking"** or **through/along**[67][70]:

**Uses**:
- **Reason/cause**: *Obrigado por tudo* = \(obɾiˈɡadu puɾ ˈtudu\) (Thanks for everything - because of)
- **Duration**: *Estudei por duas horas* = \(eʃtuˈdej puɾ ˈdwas̃ ˈɔɾɐʃ\) (I studied for two hours)
- **Agent (passive)**: *Foi escrito por ela* = \(ˈfoj eʃˈkɾitu puɾ ˈɛlɐ\) (It was written by her)
- **Means/method**: *Por telefone* = \(puɾ tɪˈlɛfɔnɪ\) (By phone), *pela metade* = \(ˈpɛlɐ meˈtadʒi\) (by half)
- **Price/exchange**: *Comprei por 10 euros* = \(kõˈpɾej puɾ ˈdɛs̃ ˈew̃ɾuʃ\) (I bought it for 10 euros)
- **Movement through**: *Passar por aqui* = \(paˈsaɾ puɾ aˈki\) (Pass through here)
- **Rate**: *Duas vezes por semana* = \(ˈdwas̃ ˈvɛzis̃ puɾ siˈmanɐ\) (Twice per week)

## 14. Word Order and Syntax

### Basic SVO Structure

Portuguese follows **Subject-Verb-Object** like English and Spanish[5][79][82]:
- *João come pão* = \(ʒuˈɐ̃w̃ ˈkomu ˈpɐ̃w̃\) (João eats bread)

**However, Portuguese is more flexible than English**[5][79][82]:

### Flexible Word Order

Can emphasize different elements[79]:
- **OSV**: *Pão come João* = \(ˈpɐ̃w̃ ˈkomu ʒuˈɐ̃w̃\) (Bread is what João eats - emphasis on bread)
- **VSO**: *Come João pão* = \(ˈkomu ʒuˈɐ̃w̃ ˈpɐ̃w̃\) (João does eat bread - emphasis on action)

### Questions

**Unlike Spanish**, Portuguese doesn't require inversion for questions[2]:
- Statement: *Você quer café* = \(voˈse ˈkɛɾ kaˈfɛ\) (You want coffee)
- Question: *Você quer café?* = \(voˈse ˈkɛɾ kaˈfɛ\) (Do you want coffee?) - same word order!
- With question word: *Onde você mora?* = \(ˈõdʒi voˈse ˈmoɾa\) (Where do you live?)

## 15. Diminutives and Augmentatives

Portuguese uses these **extremely frequently**[77][80][83] for size, affection, irony.

### Diminutives

**Common suffixes**: **-inho/-inha** (most common), **-zinho/-zinha**:
- *gato* = \(ˈɡatu\) → *gatinho* = \(ɡaˈtʃĩɲu\) (little cat, kitten)
- *café* = \(kaˈfɛ\) → *cafezinho* = \(kafeˈzĩɲu\) (small coffee)
- *casa* = \(ˈkazɐ\) → *casinha* = \(kaˈzĩɲɐ\) (little house)
- *flor* = \(ˈfloɾ\) → *florzinha* = \(fluɾˈzĩɲɐ\) (little flower)

**Uses**:
- Literal smallness

## 18. European vs. Brazilian Portuguese: Key Differences

### Pronunciation

**European**: Vowel reduction, more closed sounds, drops unstressed syllables[95][98]

**Brazilian**: Open vowels, clearer pronunciation, more nasal[95][98]

### Gerund vs. Infinitive

**European**: *a* + infinitive
- *Estou a estudar* = \(eʃˈtow a eʃtuˈdaɾ\) (I am studying)

**Brazilian**: Gerund (like English/Spanish)
- *Estou estudando* = \(eʃˈtow eʃtuˈdɐ̃du\) (I am studying)

### Pronoun Placement

**European**: Enclisis by default (after verb)
- *Amo-te* = \(aˈmu tɪ\) (I love you)

**Brazilian**: Proclisis more common (before verb)
- *Te amo* = \(tɪ ˈɐmu\) (I love you)

### Tu vs. Você

**European**: Uses *tu* = \(tu\) (informal) more frequently

**Brazilian**: Prefers *você* = \(voˈse\) in most contexts

### Vocabulary

Different everyday words[92][95]:
- Bus: EP *autocarro* = \(awtuˈkaʁu\) vs. BP *ônibus* = \(ˈõnibuʃ\)
- Bus stop: EP *paragem* = \(paˈɾaʒẽj̃\) vs. BP *ponto de ônibus* = \(ˈpõtu dʒi ˈõnibuʃ\)
- Train: EP *comboio* = \(kõˈbɔju\) vs. BP *trem* = \(ˈtɾẽ\)
- Cell phone: EP *telemóvel* = \(telɪˈmɔvɛʊ\) vs. BP *celular* = \(seluˈlaɾ\)

## 19. Learning Strategy for Multilingual Adults

### Leverage Your Spanish

**Similarities to exploit**:
- 89% lexical similarity - recognize cognates[6]
- Same SVO word order
- Similar verb conjugation patterns
- Grammatical gender system
- Both use *ser/estar* distinction

**Key differences to focus on**:
1. **Pronunciation** - especially nasal vowels
2. **Future subjunctive** - doesn't exist in Spanish
3. **Personal infinitive** - unique to Portuguese
4. **Object pronoun placement** - more complex
5. **Extensive contractions** - mandatory usage
6. **False friends** - memorize the critical ones

### Use Your French

- Many French borrowings in Portuguese
- Similar nasal sounds (though Portuguese nasalization is different)
- Understand concept of vowel quality differences

### Use Your German

- Understand case-like pronoun system
- Appreciate separable/inseparable prefixes (similar to Portuguese compound verbs)

### Use Your Flemish/Dutch

- Word order flexibility
- Compound structures

### Recommended Learning Order

**Phase 1 - Foundation (A1)**:
1. Master pronunciation (especially nasals)
2. Present tense regular verbs
3. Ser vs. estar
4. Essential irregular verbs (ter, ir, fazer, poder, querer)
5. Basic articles and contractions
6. Subject and reflexive pronouns

**Phase 2 - Core Grammar (A2)**:
7. Preterite vs. imperfect
8. Object pronouns and placement rules
9. Present subjunctive basics
10. Future tense
11. All preposition contractions
12. Adjective agreement and placement

**Phase 3 - Advanced Features (B1)**:
13. **Future subjunctive** (Portuguese-specific!)
14. **Personal infinitive** (Portuguese-specific!)
15. Full subjunctive system
16. Complex pronoun combinations
17. Passive voice
18. Conditional and hypothetical constructions

As a multilingual adult learner with Romance language background, you have significant advantages learning Portuguese. Your Spanish gives you immediate recognition of most vocabulary and grammar patterns. Focus your intensive study on Portuguese's **unique features**:

**Portuguese exclusives to master**:
1. Nasal vowel system
2. Future subjunctive
3. Personal infinitive
4. Object pronoun placement (European style)
5. Extensive mandatory contractions

**Your Spanish is both help and hindrance**: It provides instant comprehension but can create interference, especially with:
- Pronunciation (resist Spanish pronunciation)
- False friends (memorize the critical ones)
- Pronoun placement (Portuguese is more complex)
- Subjunctive usage (Portuguese has more tenses)

With focused study on Portuguese-specific features while leveraging your existing Romance language knowledge, you can achieve conversational fluency rapidly. Prioritize **listening practice** to internalize pronunciation patterns, especially the distinctive nasal sounds that define Portuguese phonology.
